El desarrollo de A.I.D. (Auditor Inteligente de Dispapeles) surge con el propósito de facilitar y optimizar el trabajo de las analistas, agilizando los procesos de auditoría documental y reduciendo al máximo los tiempos empleados en su ejecución.

// Instalar Python
Instalar python 3.14.7 (Kevin suministra ejuecutable para instalación) El administrador de sistemas debe dar permiso para añadir ruta al PATH

// Instalar entorno virtual .venv
py -3.14 -m venv .venv

// Instalar las dependencias necesarias
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

// Comando para ejecutar la aplicación de escritorio dentro del entorno virtual venv: 
.\.venv\Scripts\python.exe .\A.I.D.py
